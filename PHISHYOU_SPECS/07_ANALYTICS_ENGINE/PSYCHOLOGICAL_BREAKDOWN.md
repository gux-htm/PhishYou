# PhishYou: Psychological Breakdown Report

---

## Overview

The psychological breakdown is the AAR section that explains *why* a target complied or resisted in human terms. It converts signals, triggers, and trajectory data into a narrative a manager or HR lead can act on — without psychobabble and without shaming.

---

## 1. Report Structure (Per Target)

```
1. Headline outcome          (Compromised / Resisted / Blocked + resilience score)
2. Dominant vulnerability    (which trigger broke through, with evidence quote)
3. Resistance profile        (trajectory chart + peak moments)
4. Decision timeline         (key moments annotated)
5. Defenses shown            (what the target did right — always present)
6. Coaching recommendations  (specific, trainable behaviors)
```

---

## 2. Vulnerability Classification

Each compromised target receives a primary vulnerability label:

| Label | Pattern | Typical coaching focus |
|-------|---------|------------------------|
| **Authority deference** | Compliance after title/policy citation; low questioning | Verification-protocol training; "authority still verifies" |
| **Urgency capture** | Latency compression + skipped checks under deadline | Time-pressure drills; standing rule: urgency ≠ bypass |
| **Fear response** | Compliance immediately after threat framing | Threat-handling scripts; who to call when scared |
| **Social conformity** | Compliance after "everyone else did" claims | Independent verification culture |
| **Helpfulness trap** | Reciprocity-driven; can't refuse a "favor" | Boundary scripts for colleagues/vendors |
| **Cognitive overload** | Complied during high-load window, multi-step request | Workload-aware procedures; deferral rights |
| **Familiarity bias** | Trusted known-contact persona without verification | Identity verification even for known senders |

Resistant targets receive a **strength label** (Verifier, Reporter, Blocker, Stonewaller) that coaching reinforces.

---

## 3. Evidence Requirements

Every claim in the breakdown cites evidence:
- Direct quote of the AI message that shifted resistance
- Target's reply showing the shift
- Timestamp gap (how fast the shift happened)

No speculative psychology. The report describes **observed behavior under controlled stimulus**, not personality.

---

## 4. Sample Breakdown (Condensed)

```
TARGET: Alice J. (Finance) — OUTCOME: COMPROMISED — RESILIENCE: 0.38

DOMINANT VULNERABILITY: Authority + Urgency capture
  • Resisted well for 3 turns (peak resistance 0.61) — asked for verification twice
  • Broke at 14:32 when "CFO" voice note arrived + deadline moved to 15:00
  • Resistance fell 0.61 → 0.18 in one turn (Crack trajectory)

DECISION TIMELINE
  14:05  Received email directive           → questioned legitimacy ✅
  14:12  WhatsApp follow-up                 → asked to verify ✅
  14:28  Voice note + tightened deadline    → complied ✗ (2 min later)

DEFENSES SHOWN
  • Initiated verification twice before compromise
  • Did not share OTP when prompted (stopped at credentials)

COACHING
  1. Voice messages are not verification — callback via known number only
  2. Deadline pressure from unexpected channels = automatic escalation to manager
  3. She was 80% of the way to a perfect defense; the gap is the last mile
```

## 5. Aggregated Psychological Report (Org Level)

- Vulnerability distribution by department (e.g., Finance: 60% authority-capture)
- Trigger susceptibility heatmap
- Fatigue-window exposure (compromises clustered by hour)
- Language-cohort differences (English vs Roman Urdu campaigns)

---

## 6. Ethical Presentation Rules

- Reports identify individuals only to roles with `pii:read` grant; others see aggregates.
- Language is developmental, never punitive; templates reviewed against `PSYCHOLOGICAL_SAFETY_NOTES.md`.
- No report may be used as input to disciplinary processes (org attestation clause).
- Target can request their own breakdown — full transparency right.
